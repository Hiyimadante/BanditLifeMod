# 🏴 Bandit Life Mod for Mount & Blade II: Bannerlord

## 📋 Descripción

Este mod te permite convertirte en un bandido verdadero en Mount & Blade II: Bannerlord.

## ✨ Características

✅ Convertirse en bandido en cualquier hideout
✅ Todas las facciones te declaran guerra automáticamente
✅ Reclutar bandidos de patrullas enemigas
✅ Base de operaciones bandida
✅ Sistema de persistencia y guardado

## 📥 Instalación

1. Descarga la carpeta BanditLifeMod
2. Cópiala a: `C:\Users\TuUsuario\AppData\Local\Mount and Blade II Bannerlord\Modules\`
3. Activa el mod en el launcher de Bannerlord
4. ¡Disfruta!

## 🎮 Cómo Usar

1. Ve a una hideout en el mapa
2. Selecciona "Unirse a la vida de bandido"
3. ¡Todas las facciones te declaran guerra!
4. Recluta más bandidos encontrándote con patrullas

## 📦 Requisitos

- Bannerlord 1.4.8+
- .NET Framework 4.7.2
